Oracle VirtualBox

VirtualBox es un software de virtualización multiplataforma. Te permite crear "computadoras dentro de tu computadora" para probar Linux sin riesgos.

Requisitos mínimos

  • Windows 10/11, macOS 12+ o Ubuntu 22.04+ (¿No sabes las specs de tu PC? Presiona Win + Pausa)
  • Mínimo 4 GB de RAM libres
  • Virtualización activada en la BIOS (Verifícalo en el Administrador de tareas → Rendimiento)
  • Espacio en disco: mínimo 20 GB

Descargar e instalar VirtualBox

Ve al sitio oficial y descarga la versión para tu sistema operativo. También instala el Extension Pack, será necesario más adelante.

🌐 Ir a la página de descarga oficial

Paso 1: Sigue el enlace.

Paso 2: Da click en el GRAN boton que dice "Download" dentro del sitio oficial de VirtualBox.

Paso 3: Selecciona sistema operativo y descarga el extension pack.

🎓 Tutorial: Instalar Linux en VirtualBox

Paso 1: Crear nueva máquina virtual

Abre VirtualBox → "Nueva" → Nombre: Linux Mint → Tipo: Linux → Versión: Ubuntu (64-bit).

Paso 2: Asignar memoria RAM

Recomendado: 4096 MB (4 GB) mínimo. No excedas la zona verde del slider.

Paso 3: Crear disco duro virtual

Elige "VDI", "Reservado dinámicamente" y asigna 25 GB mínimo.

Tip final: Recuerda activar VT-x/AMD-V en la BIOS antes de empezar.
