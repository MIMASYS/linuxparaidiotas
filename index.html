ls

Lista el contenido de un directorio. Es el comando básico para ver qué archivos y carpetas hay en una ubicación.

📖 Ejemplos de uso
ls → Lista archivos simples
ls -la → Muestra TODO (incluidos ocultos)
ls -lh → Muestra tamaños en KB/MB/GB

cd

"Change Directory" - Cambia de carpeta. Te mueve por el sistema de archivos como "Entrar" en el explorador de Windows.

📖 Ejemplos de uso
cd Documentos → Entra a Documentos
cd .. → Sube una carpeta (atrás)
cd ~ → Vuelve a tu carpeta personal

chmod

Cambia los permisos de archivos y carpetas. Controla quién puede leer, escribir o ejecutar algo.

📖 Ejemplos de uso
chmod +x script.sh → Hace ejecutable un archivo
chmod 755 archivo → Dueño: todo, Otros: leer+ejecutar
chmod 600 secreto.txt → Solo tú puedes leer/escribir
